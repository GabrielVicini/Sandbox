# Schoology Pop-Out
Pop Schoology's tiny embedded external-tool (LTI) iframes out into a full window, tab, or maximized view.

## Why was this tool needed?
The current website layout makes it difficult to view embedded pages, so this tool lets you open them in a new window instead. It is not a hack and does not provide any unfair advantage; it's simply a quality-of-life improvement designed to help users on smaller screens

## How to install?
Make sure Chrome Developer mode is on and drag and drop the schoology-popout folder into the Chrome extensions list. **I can't guarantee it will work on managed Chromebooks or any other weird setups that aren't just regular Chrome or a similar browser type.** Make sure you don't drag and drop other projects in this repo also into Chrome extensions.
